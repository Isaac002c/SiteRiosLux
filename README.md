# RiosLux - Agência de Eventos Premium no Rio de Janeiro

## 🎯 Sobre Este Projeto

**RiosLux** é uma agência especializada em eventos premium e serviços de concierge exclusivo no Rio de Janeiro, com foco em sofisticação, discrição e execução impecável.

Site totalmente otimizado para Google com:
- ✅ 18 URLs estratégicas
- ✅ Schema Markup completo (LocalBusiness, Service, FAQPage)
- ✅ Meta titles e descriptions premium
- ✅ Hierarquia H1-H3 semântica
- ✅ Mobile-first responsive
- ✅ Core Web Vitals otimizados

## 🚀 Quick Start

### 1. Instalar Dependências
```bash
npm install
```

### 2. Rodar Localmente
```bash
npm run dev
```
Acesse: http://localhost:3000

### 3. Build para Produção
```bash
npm run build
npm run start
```

## 🔧 Setup Google (Crítico)

### 1. Google Search Console
1. https://search.google.com/search-console
2. Adicionar propriedade: seu-dominio.com.br
3. Verificar via HTML ou DNS
4. Submeter `/sitemap.xml`

### 2. Google Analytics 4
1. https://analytics.google.com
2. Criar propriedade
3. Instalar tracking tag
4. Configurar goals: form submit, WhatsApp click

### 3. Google Business Profile
1. https://business.google.com
2. Criar perfil: "RiosLux"
3. Categoria: Event Planning Services
4. Adicionar informações e fotos

### 4. Monitoramento
Após 24-48h, verificar em GSC:
- Performance: impressões, cliques, posição
- Coverage: URLs indexadas
- Enhancements: mobile usability
